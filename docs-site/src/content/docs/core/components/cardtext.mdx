### Accessibility

- Renders the root as a plain `&lt;div&gt;` carrying only `className` and `data-name`; it sets no `role`, no `tabindex` and no ARIA attribute, so the component adds no widget semantics and nothing it renders is keyboard focusable. ([src/components/cardText/cardText.tsx#L54-L57](https://github.com/Aye-Kyawt/horizon-stays-design-system/blob/e570ee93c3cb4cdd878e7fe8a32083fecc12baee/src/components/cardText/cardText.tsx#L54))
- Renders the title as a `&lt;p&gt;`, not a heading element, so the card's name does not appear in the document's heading outline. ([src/components/cardText/cardText.tsx#L59](https://github.com/Aye-Kyawt/horizon-stays-design-system/blob/e570ee93c3cb4cdd878e7fe8a32083fecc12baee/src/components/cardText/cardText.tsx#L59))
- Destructures a fixed prop list with no rest spread, and `CardTextProps` declares `className` as its only pass-through, so a consumer cannot put `aria-*`, `id` or `role` on the rendered element through this component's API. ([src/components/cardText/cardText.tsx#L41-L52](https://github.com/Aye-Kyawt/horizon-stays-design-system/blob/e570ee93c3cb4cdd878e7fe8a32083fecc12baee/src/components/cardText/cardText.tsx#L41))
- `metadata=&#123;false&#125;` omits the rating and price block from the DOM entirely rather than hiding it with CSS, so it is absent from the accessibility tree, not merely invisible. ([src/components/cardText/cardText.tsx#L63](https://github.com/Aye-Kyawt/horizon-stays-design-system/blob/e570ee93c3cb4cdd878e7fe8a32083fecc12baee/src/components/cardText/cardText.tsx#L63))
- `review=&#123;false&#125;` omits the rating line from the DOM, and because that block is nested inside the `metadata` block, `metadata=&#123;false&#125;` removes it whatever `review` is set to. ([src/components/cardText/cardText.tsx#L65](https://github.com/Aye-Kyawt/horizon-stays-design-system/blob/e570ee93c3cb4cdd878e7fe8a32083fecc12baee/src/components/cardText/cardText.tsx#L65))
- `price=&#123;false&#125;` omits the price line from the DOM, nested inside the `metadata` block the same way. ([src/components/cardText/cardText.tsx#L71](https://github.com/Aye-Kyawt/horizon-stays-design-system/blob/e570ee93c3cb4cdd878e7fe8a32083fecc12baee/src/components/cardText/cardText.tsx#L71))
- Renders the rating value and the review count as two adjacent `&lt;p&gt;` elements with no `aria-label` and no text identifying them as a rating, so that meaning reaches assistive technology only through the strings a consumer passes as `rating` and `reviewCount`. ([src/components/cardText/cardText.tsx#L67-L68](https://github.com/Aye-Kyawt/horizon-stays-design-system/blob/e570ee93c3cb4cdd878e7fe8a32083fecc12baee/src/components/cardText/cardText.tsx#L67))
- Renders the price amount and the price period as two adjacent `&lt;p&gt;` elements with no accessible name joining them, so "121 EUR" and "per night" are announced as two separate paragraphs. ([src/components/cardText/cardText.tsx#L73-L74](https://github.com/Aye-Kyawt/horizon-stays-design-system/blob/e570ee93c3cb4cdd878e7fe8a32083fecc12baee/src/components/cardText/cardText.tsx#L73))
