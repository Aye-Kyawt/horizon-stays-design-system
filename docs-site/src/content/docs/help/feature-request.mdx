title: Request a feature
description: How to ask for a new component, variant or state.
---

Open an issue on the repository:
**https://github.com/Aye-Kyawt/horizon-stays-design-system/issues/new**

## Say what you need, not how to build it

Describe the problem in the product:
- where it happens,
- what the user is trying to do,
- which existing component comes closest, and why it isn't enough.

## Where a request goes

Every component is built from a Figma node, so a new component, variant or state starts in the
design:

1. The design is added to the Figma component file, with its documentation.
2. The component is built from that node, and tested against it variant by variant.
3. It moves up the statuses on the [Roadmap](/get-started/roadmap/), and becomes public in the
   release whose review clears it.

Some components are already on that path. Check the [Roadmap](/get-started/roadmap/) before you
file.
